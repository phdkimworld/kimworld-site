# 김박사 월드 — 미국 주식 리포트 사이트

무료 리포트 + 광고로 운영하는 정적 사이트입니다. 이 저장소에 파일을 올리면 몇 분 뒤 사이트에 반영됩니다. 서버와 비밀값이 없습니다.

## 운영자가 할 일

Claude에게 말로 시키면 됩니다. 예:

- "IONQ 리포트 써서 올려 줘" / "RGTI 리포트 숫자 최신으로 고쳐 줘"
- "애드센스 승인됐어. ca-pub-… , 인아티클 단위 번호는 …"
- "쿠팡 배너 코드 이거 넣어 줘" (대시보드에서 만든 코드 붙여 넣기)
- "광고 하나 빼 줘" / "글자 더 크게"

직접 해야 하는 것은 광고 회사 가입·승인, 도메인 연결(한 번)뿐입니다.

## 도메인 연결 (한 번)

1. Claude에게 "도메인 연결해 줘, 도메인은 ○○○" 라고 말합니다(사이트 설정을 바꿉니다).
2. 도메인을 산 곳의 DNS 설정에 아래를 넣습니다.
   - `www` 를 쓰는 경우: CNAME `www` → `phdkimworld.github.io`
   - 맨 도메인(예: example.com)을 쓰는 경우: A 레코드 4개 `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
3. GitHub 저장소 Settings → Pages → Custom domain 에 같은 도메인을 넣고 Enforce HTTPS 를 켭니다.

## 개발

```
pip install -r requirements.txt
python3 tests/test_build.py      # 검사
python3 build.py --drafts        # dist/ 에 초안까지 빌드
```

에이전트 작업 규칙은 `AGENTS.md`에 있습니다.
