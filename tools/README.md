# tools — 영상·리포트 제작 키트

`kim-world-stock-studio` 스킬이 작업 때마다 복사해 쓰는 코드입니다. 사이트 빌드와는 관계없습니다(배포 결과물에 들어가지 않음).

| 폴더 | 내용 |
| --- | --- |
| `charts/make_chart.py` | 리포트 대표 가격 차트 PNG |
| `thumbkit/` | 유튜브 썸네일(배경 장면 + 가운데 제목 합성) |
| `tts/` | 슈퍼토닉 남성 TTS 실행 스크립트와 문장 시각표 생성 |
| `slidekit/` | 나레이션 문장에 맞춰 바뀌는 슬라이드 영상 |
| `midroll/make_assets.py` | 영상 중간 사이트 안내 이미지 |

고칠 때는 이 폴더의 파일을 고쳐 커밋합니다. 스킬 문서에는 코드 대신 이 경로만 적혀 있습니다.
